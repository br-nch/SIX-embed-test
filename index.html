Reading the results

A blocked frame shows a blank box or a "refused to connect" icon. The browser's load event fires either way, so the status lines are only a hint. The reliable signal is the console: open DevTools and look for Refused to frame ... because an ancestor violates the following Content Security Policy directive: "frame-ancestors ...". The network tab shows the response's Content-Security-Policy header, which lists the allowed ancestors, and any leftover X-Frame-Options header.
